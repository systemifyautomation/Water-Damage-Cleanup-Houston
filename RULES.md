# Project rules

## Rule N)1 — Section backgrounds and readable text

All `section` elements must use a white background (`#ffffff`). The only exception is the site footer, which must use a black background (`#000000`).

Never place white text on a white background. Any white text must be displayed on a dark background with sufficient contrast.

## Rule N)2 — Code organization

Keep page files semantic and content-focused. Shared presentation belongs in `assets/css/`; shared behavior belongs in `assets/js/`. Do not add inline `style` or inline JavaScript event-handler attributes to HTML pages.

## Rule N)3 — Brand palette

Use only black (`#000000`), white (`#ffffff`), and navy (`#0c1744`) for custom site styling.
